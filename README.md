Quản Lý Nhà Hàng (Restaurant Management System)
Dự án hệ thống quản lý nhà hàng được xây dựng bằng Java.

🚀 Các chức năng chính:
Quản lý đặt bàn: Xử lý các ràng buộc khi khách hàng đặt chỗ.

Đặt món: Hệ thống chọn món ăn và quản lý đơn hàng.

Quản lý vận hành: Hỗ trợ điều phối hoạt động nhà hàng.

🛠 Công nghệ:
Ngôn ngữ: Java

Cấu trúc: Sử dụng Java Swing/AWT (thường thấy trong các repo Java thuần) cho giao diện.
